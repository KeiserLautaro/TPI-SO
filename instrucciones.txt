================================================================================
INSTRUCCIONES DE EJECUCIÓN Y USO - SIMULADOR TPI SISTEMAS OPERATIVOS
================================================================================

Simulador de Asignación de Memoria con Particiones Variables (MVT Best-Fit)
y Planificación de CPU a Corto Plazo (SRTF Apropiativo).
Implementado bajo el paradigma de PROGRAMACIÓN ESTRUCTURADA (sin clases / sin POO).
Cátedra de Sistemas Operativos - UTN Facultad Regional Resistencia.


--------------------------------------------------------------------------------
1. CÓMO EJECUTAR EL PROGRAMA (INDICACIÓN BREVE)
--------------------------------------------------------------------------------
Dispone de dos formas sencillas de ejecución:

• OPCIÓN A (Recomendada / Directa):
  Hacer doble clic sobre el archivo ejecutable:
  👉 'ejecutar_simulador.bat'

• OPCIÓN B (Desde Terminal o PowerShell):
  Abrir PowerShell o CMD y ejecutar los siguientes comandos (las comillas son
  obligatorias debido al espacio en el nombre de la carpeta):
  
  cd "c:\Users\lauta\Documents\TPI SO"
  python simulador.py

--------------------------------------------------------------------------------
2. GUÍA RÁPIDA DE USO DEL SIMULADOR
--------------------------------------------------------------------------------
1. Pantalla de Inicio / Bienvenida:
   - Puede cargar procesos desde un archivo con el botón "📁 Seleccionar Archivo CSV / TXT"
     (se incluye el archivo de prueba 'procesos.csv').
   - O bien cargar los procesos manualmente con el formulario (ID, Tamaño, TA, TI).
   - Presionar el botón "🚀 INICIAR SIMULACIÓN CON ESTOS PROCESOS".

2. Pantalla de Simulación:
   - "⏭ Siguiente Ciclo (T + 1)" [Verde]: Avanza un ciclo de reloj.
   - "⏮ Ciclo Anterior (T - 1)" [Verde]: Permite retroceder en el tiempo al ciclo anterior.
   - "⏩ Siguiente Evento" [Azul]: Avanza automáticamente hasta el siguiente arribo o fin de proceso.
   - "🔄 Reiniciar (T=0)" [Naranja]: Restablece la memoria y los procesos al inicio.
   - "📊 Informe Estadístico" [Púrpura]: Muestra el resumen con TR, TE, TRP, TEP y Rendimiento.
   - "🏠 Volver a Inicio / Carga" [Gris]: Regresa a la pantalla de bienvenida.
